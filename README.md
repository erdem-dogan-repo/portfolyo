# Data Analist & Business Intelligence Portfolio

Modern ve responsive bir Data Analist/Business Intelligence portföy web sitesi.

## Özellikler

- ✅ Tamamen responsive tasarım (Bootstrap 5)
- ✅ Modern ve profesyonel arayüz
- ✅ Smooth scroll animasyonları
- ✅ İnteraktif istatistik sayaçları
- ✅ Proje portföyü bölümü
- ✅ Tek dosyada tüm kod (HTML, CSS, JS)

## Teknolojiler

- HTML5
- CSS3
- JavaScript (Vanilla)
- Bootstrap 5.3.2
- Bootstrap Icons

## Kullanım

Dosyayı tarayıcınızda açarak görüntüleyebilirsiniz:

```bash
open index.html
```

veya

```bash
# Python ile basit bir HTTP sunucusu başlatın
python3 -m http.server 8000
```

Sonra tarayıcınızda `http://localhost:8000` adresine gidin.

## Lisans

Bu proje kişisel portföy amaçlıdır.
